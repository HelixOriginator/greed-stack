# The Greed Stack

The Greed Stack is an open cultural and systems framework that explores how greed evolves from desire into normalized social, economic, and technological structures.

Rooted in Indic philosophy and informed by modern systems thinking, this project treats greed not as a moral failure but as a layered phenomenon shaped by incentives, design choices, and cultural reinforcement.

---

## What is the Greed Stack?

Greed has historically been understood as *lobha* in Indic texts, a condition that emerges when desire is repeatedly fulfilled and left unchecked. In contemporary society, this dynamic is amplified by platforms, markets, and technologies designed around growth, engagement, and extraction.

The Greed Stack maps this evolution across distinct layers, showing how individual impulses scale into systemic behavior.

---

## The Five Layers

### 1. Impulse Layer  
Greed begins as desire that has been rewarded. Repetition strengthens attachment and expectation.

### 2. Justification Layer  
Rationalizations emerge that normalize excess and suppress ethical friction.

### 3. System Layer  
Institutions, platforms, and incentive structures encode greed into processes and metrics.

### 4. Normalization Layer  
When greed becomes widespread, it stops appearing as greed and starts looking like success, ambition, or necessity.

### 5. Liberation Layer  
Awareness, restraint, and conscious redesign of incentives allow systems and individuals to move beyond endless wanting.

---

## Why This Project Exists

Modern discussions of greed often focus on individuals while ignoring systems. Ancient texts diagnose the opposite problem by addressing inner states without modern structural context.

The Greed Stack bridges this gap by:
- Translating philosophical insight into systems language  
- Making invisible incentive structures visible  
- Offering design and cultural alternatives to extraction-driven models
